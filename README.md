# Workout Application Backend

## About the Project

This is a backend application built using Python and Flask. It allows users to manage workouts and exercises.

## Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- Marshmallow
- Pytest

## Features

- View all workouts.
- View a specific workout.
- Create and delete workouts.
- View all exercises.
- View a specific exercise.
- Create and delete exercises.
- Add exercises to workouts.
- Validate input data.
- Test the application.

## Running Tests

To run the application tests, use the following command in the terminal:

```bash
pipenv run python -m pytest -v
```

## Purpose

This project helps me practise building REST APIs, working with databases, validating data, and writing automated tests as part of my software engineering studies.
